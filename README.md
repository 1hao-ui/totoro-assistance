## 项目说明

面向微信小程序「龙猫体育锻炼」的校园跑辅助与技术研究工具：读取任务与线路数据、管理本地路线、生成轨迹预览、执行参数校验，并提供服务端结果查询与本地日志功能。

本仓库主要面向微信小程序后端接口。早期针对旧 App 后端 `app.xtotoro.com` 的代码已在 `1.1.1` 轮次中移除。历史版本见 tag `1.0.1`–`1.0.4`。

兼容性、任务参数及判定结果可能因学校配置和服务端版本而异。具体以实际接口响应和学校系统记录为准。

## 使用说明

### 方式 A：下载 Windows 版本

进入 [Releases](https://github.com/dboycht/totoro-heaven/releases) 页面，下载对应版本的 `totoro-heaven-<版本>.zip`。

解压后运行 `totoro-heaven.exe`。该版本包含 Node.js 运行时，通常无需另外安装 Node.js 或项目依赖。

程序启动后默认访问：

`http://localhost:3000`

支持 Windows 10/11 x64。

### 方式 B：从源码运行

```bash
npm install
npm run dev
npm run verify
npm run test:mp
npm run typecheck:mp
npm run typecheck:ui
npm run typecheck:vue
npm run check:wiring
npm run build
npm run sea
```

开发地址为 `http://localhost:3000`。各命令的具体用途与执行条件以项目 `package.json` 及相关脚本为准。

## 授权说明

⚠️ **从本仓库构建 / 打包的版本需要授权证书才能使用。**

软件内「**授权**」页会显示本机的**机器码**。首次使用时：

1. 打开「授权」页，复制**本机机器码**（形如 `A1B2-C3D4-E5F6-0718`）；
2. 把机器码发给**授权证书的签发者**，换取一张**授权证书**；
3. 把证书**整段**粘贴回「授权」页（换行与空格会被自动忽略），点「激活」。

激活一次后可**离线使用**：证书含「正常有效期 + 离线宽限期」，验签完全在本机完成，不联网。
到期前重新获取一张新证书粘回即可续期；换机器需要用**新机器码**重新签发。

> **未授权时不会让你在功能页里瞎点**：程序会自动把你带到本页并说明原因。
> 顶栏常驻一个授权状态标识；到期前 7 天起显示「剩 N 天」，进入离线宽限期时显示「宽限期」并提示续期。

### 开发与打包的差异（⚠️ 最容易踩的坑）

| 场景 | 是否校验授权 |
| --- | --- |
| `npm run dev` | **不校验**（开发旁路，便于调试） |
| `npm run sea` 打包出的 EXE | **强制校验** |

想在本机按正式版口径自测：设 `TOTORO_LICENSE_STRICT=1` 后再启动。

### 🔑 关于私钥（只与签发者有关）

签发证书需要**私钥** `tools/keys/license-private.pem`，它**不在本仓库中**（已被 `.gitignore` 排除），
由签发者单独保管。因此要注意两点：

- **没有私钥的人可以开发、可以跑测试，但无法为自己打包出的版本生成可用授权** ——
  打包发布前请先确认授权来源；
- **整个项目只应存在一把密钥对**。重跑 `node tools/license-keygen.ts --force` 会更换公钥，
  **已发出的所有证书立即作废**；也不要为了"自己也能签发"而各生成一把 ——
  两把密钥会互相签出对方验不过的证书。

完整流程（签发参数、台账、排查表）见 [`tools/README-授权使用.md`](tools/README-授权使用.md)。

## 使用流程

1. **准备会话信息：** 根据项目支持的方式准备经过授权的测试会话。
2. **读取任务数据：** 查看账号信息、任务约束、线路点列及相关配置。
3. **查看路线：** 根据实际任务选择线路，或在本地编辑器中管理用于模拟和预览的路径。
4. **参数检查：** 查看里程、配速、时长、拟合度及任务时间范围等参数。
5. **结果核对：** 查看本地操作记录及服务端实际返回的结果。

涉及实际账号和业务记录的操作，应以学校系统的验证要求及服务端处理结果为准。

## 技术要点

- **接口层：** 维护 57 个端点的元数据，包括路径、方法、业务负载位置及 Token 要求。
- **响应解析：** 处理 `status`、`code`、`header.bizCode` 等不同响应字段。
- **身份验证：** 使用 `Authorization: Bearer` 请求头；登录态失效判据包含 `header.bizCode == -199`。
- **多租户：** 根据账号的真实 `schoolCode` 解析学校 `domainUrl`。
- **线路分组：** 根据坐标进行聚类，区分不同校区并显示距离信息。
- **轨迹计算：** 使用全局弧长推进、相关抖动及路线采样等算法生成本地预览数据。
- **拟合度：** 官方路线采样点与轨迹折线之间的距离用于计算拟合度；最终判定由服务端执行。
- **提交状态：** 区分处理中、已确认、失败及结果未知等状态，避免将网络超时直接视为业务失败。
- **本地代理：** 前端通过 `/api/mp/*` 与本地服务通信；上游域名受白名单限制并使用 HTTPS。
- **测试体系：** 包含单元测试、类型检查、接线契约检查和构建产物验证。

## 日志与排查

顶栏「日志」页提供本地事件日志和服务端文件日志。

| 层 | 位置 | 记录内容 |
| --- | --- | --- |
| 本机事件日志 | 浏览器 `localStorage`，最多保留最近 500 条 | 数据读取、配置检查、操作步骤、错误信息和结果状态 |
| 服务端文件日志 | `%TEMP%\totoro-heaven-runtime\logs\app-YYYY-MM-DD.log` | 接口端点、HTTP 状态、业务响应摘要、耗时、字节数及请求字段摘要 |

服务端日志按天切分，保留 7 天，单项上限 20 MB。界面支持等级和类别筛选、关键字搜索、复制、清理及打开日志目录。

日志中的 Token、`Authorization`、学号及姓名按项目规则脱敏。分享诊断文件前仍应检查是否包含其他敏感数据。

## 隐私与安全

- 会话数据按项目设计存放在本机 `localStorage` 的 `mp_session` 中。
- 本地扫描器通过 `OpenProcess(PROCESS_VM_READ)` 读取相关进程信息；应仅用于本人设备和获授权的调试场景。
- 扫描器与界面通过本机端点通信，并使用一次性 nonce 与同源校验。
- 上游请求受域名白名单限制，并强制使用 HTTPS。
- 项目使用 Vue 文本插值处理动态内容，不使用 `v-html` 或 `innerHTML`。
- `.har`、`.saz` 等抓包材料及解析产物由 `.gitignore` 排除。
- 项目包含敏感字段脱敏及相关测试。
